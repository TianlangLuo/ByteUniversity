Features in this website:

**Active Learning, Not Passive Reading:** Content reveals one card at a time, with checkpoint questions blocking progress until each concept is understood — no skimming allowed.

**Spaced Repetition Built In:** A smart calendar schedules when to revisit each topic based on quiz performance, using the same memory science as Anki.

**XP & Avatars:** Every correct answer and completed subtopic earns XP, spent in an avatar shop to keep motivation high throughout revision.

**18 Unlockable Badges:** Early Bird, Week Warrior, Perfectionist and more — rewarding genuine study habits, not just time on screen.

**Three Playable Games:** Snake, Memory Match and Pac-Man turn vocabulary drilling into something students actually want to do.

**Podcast:** A full audio episode covering every Topic 5 subtopic — ideal for commutes or winding down after a study session.

**Craig & Dave Videos:** All 8 official Edexcel Topic 5 videos linked and described in the Resources section.

**Curated Further Reading:** Documentaries, TED talks and peer-reviewed journals connecting GCSE concepts to real-world events — from Snowden to Amazon's biased hiring AI.

**Covers the Full Spec:** All 7 subtopics, 60+ flashcards, 40+ quiz questions and inline diagrams — everything for Topic 5 in one place.
